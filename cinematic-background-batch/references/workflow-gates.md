# 工作流与确认关卡

## 顺序

先抽原帧并整理 → B0人物/造型/背景确认与G0输出规格选择 → M1校验 → 少量完整首帧样图 → G1 → 全部首帧 → G2 → 视频短样 → Q1 → 批量视频。

B0/G0可以在同一条用户回复中一次确认。图片项目省去视频模型和视频分辨率选择，仍须确定目标画幅。所有视频项目都在样图前确定视频规格，以免构图返工。

| 关卡 | 必须展示的内容 | 通过后才可做 |
|---|---|---|
| B0 | 人物、角色、原造型、目标造型、视频数量；逐片对应表；是否换造型与范围；目标背景和TVC光景方案 | 准备确定方案的生图任务 |
| G0 | 实际可用的视频模型、分辨率与像素尺寸、画幅及构图处理方式 | 开始制作同画幅样图 |
| M1 | IMAGE2.0/2.5的真实型号映射；原生1K及真实支持尺寸 | 提交当前图像任务 |
| G1 | 人物已经进入目标背景、完成灯光/获准造型的少量完整首帧；编号与面部对照 | 批量制作全部首帧 |
| G2 | 每个视频对应的完整首帧和问题；每条选择一版 | 任何视频生成，包括短样 |
| Q1 | 实际视频短样及表演、脸、时序边缘、灯光、场景、音轨观察 | 批量视频 |

M1是自动规格检查，不额外要求一次用户确认。Q1是技术验收；不默认新增人工看片门。用户要求时可额外增加，不能擅自删除现有门。

## 确认必须具体

B0：“共1个演员、2个角色、2种原造型；两种造型都保留。全部换成暖木餐厅，按你列出的柔光与实景灯方案。”

G0：“视频选【实际模型】，生成【明确分辨率与像素尺寸】，画幅【比例】，构图【保留/仅扩背景/批准裁切】。”

G1：“样图01选A、02选B，可以批量制作全部首帧。”

G2：“这批每条选中的首帧全部通过，可以开始视频。”

不能把“背景方案不错”当成已确认生成的完整首帧；不能把“可以制作skill”当作实际项目许可。保存原文与真实消息引用，不编造作者或消息ID。已确认信息继续沿用，只补尚缺项。

## 审图覆盖

代表样图需覆盖所有原造型、所有场景组；有双人同框的场景必须展示双人同框效果。默认样图累计限额4张，失败/取消仍计数。覆盖不足先拆组或获用户明确授权调整额度，不冒用样图阶段批量生成。

完整审图图必须包含源人物、选定背景、最终计划的灯光及获准造型。空背景、别人的广告图、只裁脸图片和提示词说明都不能单独通关。模型参数和文件尺寸通过只证明规格，不证明脸没变或融合合格。

## 变更与恢复

- 人物/造型/背景或对应参考变化：B0失效；重新确认并重新生成/审查相关首帧。
- 视频模型、分辨率、画幅、构图方案变化：G0失效；G1/G2/Q1旧版本不能继续使用。
- 生图型号、配置、源片、参考和提示词变动：相应内容哈希检查失败。审批保守绑定整批，可先拆小项目减少返工。
- 重新登记samples清空后续审批；仅替换frames使G2/Q1失效。
- 1.0项目缺少新门、任务请求及原生1K回执，不能直接继承旧审批。可保留源文件重新建1.1项目。

同一消息可提供多个门的有效确认，但还没有展示的效果图不可能提前获G1/G2。任务超时先查询；unknown不重复提交。失败默认每项最多重试2次，改方案返回对应确认门。
