# 提示词知识库

## 结构

按任务选择必要槽位：编辑目标 → 输入用途 → 场景与材质 → 灯光 → 透视与接触 → 保留项 → 时间连续性 → 输出范围。不要把所有模板堆在一次请求里。

局部视频编辑优先短而明确；空景与视觉设计用完整摄影描述。正向描述优先，只在平台确实支持时传独立负面词。文字中的保持/禁止不是技术保证。

## 参考归属

原视频管口型、动作、表情、机位和时间；原帧管构图、物体与接触；人物照管身份参考，不能覆盖服装和表情；广告照管场景与光，不引用其中人脸；批准帧管该镜头视觉终点。

只有实际上传/绑定的素材可称为参考。平台占位符和角色参数必须按当前真实API/UI转换，不把某平台的@video1语法当通用格式。

| 空泛词 | 具体表达方向 |
|---|---|
| 高级酒店 | 暖灰石材、深木饰面、可信过道尺度、克制家具 |
| 电影光 | 镜头左前侧大柔光，弱正面补光，自然暗部层次 |
| TVC质感 | 服务具体产品的布景、真实材质、自然皮肤、视觉主次 |
| 融合自然 | 光源、透视、接触阴影、反射色、景深、锐度一致 |
| 8K高清 | 指定实际输出规格，保留源片可见细节；提示词不升级像素 |

固定机位不要额外写推镜、摇镜、广角、走动或复杂动作。只有脚入镜才要求足底接触；坐姿要求座椅支撑。

## 模板使用

`../assets/prompt-templates.json`包含：单人首帧、双人首帧、背景空景、人物重打光、同演员两角、原视频编辑、双人时序、背景轻动、局部灯光修正、边缘接触修正和英文简版。

填完变量再提交，用户不用写JSON。保留提示词文本、所用真实参考和模型参数。只有接口确实有seed/strength/参考权重才记录它们，不编造通用最佳值。

## 迭代

每次优先解决一项：场景、灯光或人物改动。具体指出“左脸变窄”“右手与杯子有缺口”，而非只写“更像本人”“更真实”。发生身份漂移时回到原帧，不反复编辑已漂移版本。不得把新生成五官当修复目标。

## 1.1硬参数与造型例外

模型与分辨率使用实际请求参数锁定：IMAGE2.0或IMAGE2.5、原生1K，不依赖提示词自报型号。提示词绑定用户G0画幅，不继续死写“原画幅”与目标冲突。B0批准换造型时，仅替换对应衣帽/妆发保留句；五官、表情与原表演不放开。

先让用户确认人物与造型数、是否换造型、目标背景，再生成带人物与背景的完整首帧。G1/G2必须看完成融合与布光的实际图片，空景不能代替。
