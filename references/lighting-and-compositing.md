# 商业灯光与实拍合成

## 设计次序

确定内容与产品的空间需求，再定布景材质、可信尺度、相机高度、地平线、人物到背景距离和留白。为整个活动范围补全背景；人物坐着或拿着产品时保留支撑和接触。

每套方案写清：主光方向/软硬、补光相对强弱、轮廓光是否需要、背景实景灯或窗光来源。统一透视、阴影方向、反射色、景深、锐度与噪点。镜头参数仅作为成像风格，不擅自改变源片视角。

| 幅度 | 操作 | 限制 |
|---|---|---|
| 光色匹配 | 曝光、白平衡、色彩、背景适配 | 不能等同改光源方向 |
| 受控重打光 | 大柔光塑形、合理补光、克制轮廓光 | 检查五官结构、皮肤和时序 |
| 显著改光向 | 左右主光互换、日转夜、明显硬光 | 更需重建，不保证原脸绝对不变，先验证 |

严格原脸像素不变与明显重打光不能同时保证。用户标准是五官和表演保留，允许合理受光变化。灯光使脸看起来像另一个人也应退回。

## 路线

原人物合成：提取遮罩，尽量保留不透明区域源像素，修边缘污染、必要光色和接触阴影。固定机位可以用稳定完整背景底图。抠像工具有时预测前景颜色，不能声称所有输出像素都是原片。

图像重打光：适合首帧设计；以原人物和新背景约束照明。IC-Light等说明仅证明图像方法存在，不代表独立逐帧执行能稳定生成视频。视频需时间连续的处理或经验证的视频编辑工具。

原视频编辑：源视频是表演与时间基准，批准帧是视觉目标，人物照只作身份参考。核查真实接口支持。普通图生视频不得直接当作口播表演保留方法。

## 缺陷修正

| 缺陷 | 优先修正 |
|---|---|
| 贴纸感 | 主光、透视、接触阴影、背景锐度、边缘反射 |
| 塑料皮肤 | 删除美颜词，减少人物生成式改动，保留纹理 |
| 脸脖断层 | 对齐受光，不直接贴回一块原脸 |
| 帽沿阴影跳动 | 检查帽子与头部轨迹及时间连续性 |
| 地板漂浮 | 地面透视、接触点、源动作 |
| 背景廉价 | 简化布景、具体材质与光比，不靠更重虚化 |
| 反射不自然 | 检查原反射保留范围，新增反射单独验收 |

双人共用同一光源逻辑但受光可以不同，不能用“统一肤色”消除两人本来的差异。

## 1.1参考与画幅

本项目采用用户广告截图提炼的TVC规则，见[tvc-art-direction.md](tvc-art-direction.md)。先由用户确认目标背景与灯光，不自动套用某个高级空间。画幅由用户选择，摄影透视依然服从源人物；获准扩展背景不代表允许拉伸脸。
